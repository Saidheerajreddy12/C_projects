# 📒 Address Book Project in C

This is a console-based **Address Book application** developed in **C** as part of my **Embedded Systems learning journey**.  
It allows users to **add, edit, search, delete, and view contact details**, with data stored persistently using file handling.

---

## 🚀 Features

- 📇 **Add Contact** – Save a new contact with name, phone number, and address  
- ✏️ **Edit Contact** – Modify existing contact details  
- 🔍 **Search Contact** – Find a contact by name or phone number  
- 🗑️ **Delete Contact** – Remove a contact from the record  
- 💾 **File Handling** – Contacts are stored in a file to maintain data persistence across runs  
- 🧠 **Structured Code** – Uses structures, arrays, and switch-case for modularity and clarity  

---

## 🧰 Concepts Used

- **Structures** for storing and organizing contact information  
- **Arrays** for managing multiple records  
- **File Handling** for reading and writing contact data  
- **String Functions, Loops, Conditional Statements, and Pointers** for input handling and validation  
- **Switch–Case Statements** for menu-driven functionality
